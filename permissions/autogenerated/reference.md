## Default Permission

Default permissions for the whisper plugin — allows all commands.

#### This default permission set includes the following:

- `allow-load-model`
- `allow-start-stream`
- `allow-push-audio-chunk`
- `allow-stop-stream`
- `allow-download-model`
- `allow-download-qwen3-model`
- `allow-download-diarization-models`
- `allow-load-diarization-model`
- `allow-set-diarization-threshold`
- `allow-merge-speakers`
- `allow-get-voice-profiles`
- `allow-delete-voice-profile`
- `allow-clear-voice-profiles`
- `allow-rename-voice-profile`
- `allow-download-silero-vad-model`
- `allow-load-vad-model`
- `allow-get-downloaded-models`
- `allow-list-backends`
- `allow-check-screen-capture-permission`
- `allow-request-screen-capture-permission`
- `allow-list-capturable-apps`
- `allow-start-sck-capture`
- `allow-stop-sck-capture`
- `allow-start-recording`
- `allow-push-recording-chunk`
- `allow-stop-recording`
- `allow-transcribe-recording`
- `allow-list-recordings`
- `allow-delete-recording`
